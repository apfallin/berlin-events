# Berlin Events 🎸🎭🎨

A minimal digest of what's on in Berlin: concerts, theatre, art, cinema and
city events — automatically deduplicated across sources.

**Live site:** https://apfallin.github.io/berlin-events/

## Sources
- 📱 **Berlin-Gigs** — community pad on Cryptpad, maintained by the Berlin DIY music community
- 🎸 **My True Intent** — mytrueintent.blogspot.com
- 🌐 **Web** — curated picks from official sites

Events from different sources are deduplicated by title + date.
